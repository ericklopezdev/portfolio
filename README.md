# Erick Lopez Portfolio

Personal portfolio focused on backend engineering, distributed systems, fintech-oriented software and cloud infrastructure.

## Stack

- React + Vite
- Tailwind CSS
- GSAP
- lucide-react
- simple-icons
- Markdown como fuente de contenido

## Scripts

```bash
npm run dev
npm run build
npm run preview
```

## Contenido

Los proyectos, experiencia y certificaciones se mantienen en:

- `src/content/projects`
- `src/content/experience`
- `src/content/certifications`

El loader React esta en `src/lib/content.ts`.
