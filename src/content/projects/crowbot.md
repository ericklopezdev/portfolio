# CrowBot - Distributed IoT & AI Assistant

CrowBot is an IoT and AI assistant designed around communication between ESP32 devices, backend services and cloud components. The project explores event-driven cloud-device synchronization, observability and failure handling.

## System Focus

- ESP32 device communication through MQTT
- Backend and device-integration components written in Go
- Concurrent processing for coordinating system components
- Event-driven architecture for cloud-device synchronization
- AI-assisted interaction using Gemini
