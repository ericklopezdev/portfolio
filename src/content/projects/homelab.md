# HomeLab - Distributed Systems & Cloud Infrastructure Lab

HomeLab is an in-development environment for studying the behavior of applications, services, networks and infrastructure as one complete system. It is designed as a practical space for experimenting with deployment, observability, failure handling and infrastructure automation.

## Lab Direction

- Deploying services across local and cloud environments using Linux, containers, AWS and Azure
- Exploring service communication, DNS, routing, access control and network segmentation
- Practicing observability through logs, metrics and resource monitoring
- Testing failure scenarios and documenting architectural decisions
- Provisioning reproducible infrastructure with Terraform
