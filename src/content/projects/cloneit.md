# CloneIt

A Go-based CLI tool for automating repository workflows through an interactive terminal interface. It focuses on developer productivity, repeatable setup and command-line ergonomics.

## Interfaces

### Go TUI
An interactive terminal interface for selecting and cloning repositories.

### Shell Script with fzf
A lightweight shell script using `gh` and `fzf` for fuzzy repository selection.

## Prerequisites

- GitHub CLI (`gh`)
- `fzf`
- `jq`
